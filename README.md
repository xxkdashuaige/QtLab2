# 实验二：简单文本编辑器（完善版）

## 功能
- 新建、打开、保存、另存为文本文件；打开/保存失败时提示原因。
- 文档修改后标题显示 `*`，关闭或新建/打开其他文件时提示保存、放弃或取消。
- 编辑菜单和工具栏：撤销、重做、剪切、复制、粘贴、全选。
- 查找下一个、单次替换、全部替换；未输入关键字和未找到时给出提示。
- 设置字体、字体颜色、编辑区背景色；开启/关闭自动换行。
- 显示/隐藏工具栏和状态栏；状态栏显示行、列和字符数。
- 关于对话框。

## 在 Qt Creator 中运行
1. 解压 `Lab2_completed.zip`。
2. Qt Creator 选择“文件 → 打开文件或项目”，打开 `Lab2.pro`。
3. 选择已安装的 Desktop Qt Kit（例如 Desktop Qt 6.11.2 MinGW 64-bit），点击 Configure Project。
4. 按 `Ctrl+B` 构建，成功后按 `Ctrl+R` 运行。

## 注意
- 该项目按 Qt Widgets / C++17 编写，适配 Qt 5.12+ 与 Qt 6 常用 API；请以本机 Kit 编译结果为准。
- 行号和定时自动保存属于实验选做项，本版本未实现。
- Git 提交记录应在实际开发修改后逐次提交，不应伪造历史。
